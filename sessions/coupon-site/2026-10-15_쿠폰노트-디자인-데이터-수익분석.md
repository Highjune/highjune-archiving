## 2. 쿠폰핀 데이터 출처·갱신 방식 (웨이백 2025-09 스냅샷 + 사내 슬랙)

- WordPress 6.9 + GeneratePress, 라이브는 Cloudflare 봇 챌린지라 archive.org 스냅샷으로 분석.
- 글은 published 2025-08-21, modified 2025-09-01 → **매월 초 같은 URL에서 제목 월·코드·기간만 수동 교체**(SEO 점수 누적).
- 할인코드 `MKTPCH1000/3000/5000`은 매니저 쿠폰 템플릿 "[마케팅 파트너 전용] 오픈채팅방 이벤트 할인쿠폰" → 출처는 **마파팀 카카오 오픈채팅방**(`open.kakao.com/o/gNkyrfLh`). 나머지(쿠폰·카드사·간편결제·항공·면세점·그랩)는 마리트 **혜택탭** `/promotions/benefit`(API `traveler/promotions/v3`, `traveler/couponPack/v1/publish`).
- 오픈채팅방 공지의 상시 코드: `PACKMKTP1000/3000/5000`(해외 투어티켓 5/10/15만↑, 등록 후 7일, 예산 소진 시 종료, 중복 불가). 마파 공식 블로그 RSS는 월 1건 수준.
- 재직자 원칙: 사내 매니저 템플릿은 보지 않고 파트너 공개 채널로만 수집.

## 4. 디자인 개편 2회 + 캐시 문제

- 1차: 표 → 쿠폰 카드, 버튼 하나로 **코드 복사(토스트) + /go 새 탭**(쿠폰핀의 "코드 적용하기"와 동일 동작), 홈 히어로, `/about`(소개·수익 구조·제휴 문의, `couponnote.contact-email` ← `CONTACT_EMAIL`), favicon.svg/png, apple-touch-icon, og.jpg(1200x630, 원본 `api/src/main/design/og.svg`, macOS `qlmanage`로 렌더).
- 사용자 캡처가 "촌스럽다" → 실제로는 **브라우저가 7일 캐시된 옛 site.css를 사용**(`Cache-Control: max-age=604800`). `spring.web.resources.chain.strategy.content` 활성화로 `site-<md5>.css` 링크 → 배포마다 자동 무효화. 기술 결론: Thymeleaf+CSS로 충분, React/별도 서버 불필요.
- 2차(쿠폰핀 톤): 티커, 어두운 히어로(월 뱃지·신뢰 지표), 섹션 패널(이모지·설명·진행중 태그), 금액 강조·BEST·강조 카드, "이렇게 쓰세요" 박스. Jenkins #3·#4 SUCCESS, 운영 확인.
- 사용자: "너무 따라한 것 같다" → 색 후보 A Ocean(틸+네이비)/B Indigo/C Sunrise 렌더 → **A 확정**. 레이아웃 후보 3개 렌더(`/tmp/couponnote-themes/`): ① 에디토리얼(좌측 히어로+쿠폰 일러스트+숫자 3개, 2열 카드) ② 코드 우선 리스트(히어로 없음, 좌측 고정 목차, 코드가 행 맨 앞) ③ 티켓(밝은 민트 히어로, 남색 스텁+절취선 티켓 카드). 추천 ③ + ① 히어로. **선택 대기.**
- 헤드리스 크롬 스크린샷 검증 루틴: 로컬 jar를 `--spring.thymeleaf.prefix=file:` / `--spring.web.resources.static-locations=file:`로 띄워 템플릿·CSS만 바꿔가며 렌더.

## 5. 마케팅파트너 수익 분석 (Redash BigQuery `mrtdata`)

- 9월 정산(`partnership_type=MARKETING`): 수익 발생 4,290명. 300만↑ 17명(1.81억), 100~300만 25명, 50~100만 45명, 10~50만 372명. **쿠폰핀 131094 = 1,536,077원, 29위.** 월 추이 7월 115 → 8월 119 → 9월 154 → 10월(14일) 106만.
- 상위: 103936 모먼트스튜디오 4,974만(법인, 마이링크 12만 개, 월 30만 클릭, 상품 링크 88%, 블로그+앱), 151304 2,075만(마이링크 58만 개, 홈 링크 76%, 링크프라이스 리셀러), 135968 1,219만(네이버 카페 88%), 134610 제이에스트래블(앱/직접 97%, 여행사), 160187·160858·159298(마이링크 거의 없음 → 다이나믹 배너/광고 네트워크). 2026-05 가입자가 4개월 만에 월 800~900만 사례.
- **쿠폰 사이트 모델**: 비마이피스 138854 876만(7위, 도메인 3개 goda-trip.com/love-trip.co.kr/korea-tripcode.com, 도착지 프로모션 82%+항공 11%)과 쿠폰핀. 클릭당 수익(수익÷클릭) 1,588원·802원 vs 큐레이션 167~480원 → **모델 단가는 최고, 승부는 트래픽**. 월 2천 클릭 ≈ 쿠폰핀, 5천 ≈ 비마이피스.
- 상위권 카테고리: SUBURB_TOUR·CITY_TOUR·NATURE_TOUR 압도, 숙소 그다음, 항공 미미(0.5%).
- 쿠폰핀 referer: couponpin 15%, 블로그 15%, 없음 65%. `gclid`는 291건 중 5건(소액 광고). referer 없음은 `rel=noreferrer` 버튼 때문 → 쿠폰핀 사이트 몫 ≈ 154만 전부. (세션 중 "광고비를 꽤 쓴다"는 추정은 정정)
- 테이블: `edw.DW_MRT_SETTLES_PARTNERSHIP_SETTLEMENT_PRODUCT_CLOSING`, `edw.DW_MRT_PARTNERS_MYLINK(short_url_id)` → `edw.DW_MRT_COMMONS_SHORT_URL_REFERER` / `DW_MRT_COMMONS_SHORT_URL(target_url_web)`. 구형 `MARKETING_ADVERTISING_LINK_REFERER`는 2024-06 중단. `partnership.sns_url`은 BigQuery에 없음(QueryPie 필요).
