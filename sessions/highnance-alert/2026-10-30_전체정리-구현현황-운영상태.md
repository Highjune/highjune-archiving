## 1. 프로젝트 한 줄 정의

성북구 돈암동 609-1(한신·한진 아파트)의 **매매 실거래 공개**와 **토지거래허가 처리 건**을 홈서버 파이썬 컨테이너가 주기적으로 폴링해 텔레그램 그룹 `오랑오순`으로 알리는 개인 재테크 알림 서비스. 재테크 공용 스키마 `highnance`의 첫 모듈(`apt_*`).

```
[highnance-alert 컨테이너 (python 3.12, 외부 포트 없음)]
   ├─ 15분  → 공공데이터포털 아파트 매매 실거래가 API (당월+전월, 성북구 전체 → 돈암동 609-1 필터)
   ├─ 1시간 → 서울부동산정보광장 토지거래허가 내역 ajax (성북구 최근 61일 → 돈암동 609-1 필터)
   ├─ home-mysql `highnance` 스키마 (apt_trade / apt_poll_run / apt_notification / apt_land_permit)
   └─ Telegram Bot API → 그룹 오랑오순
```

## 주요 발견사항 (10/29 세션 누적 + 이번 실측)

- **데이터 특성**: 한신한진은 API에서 `한신`·`한진(609-1)` 두 단지 → 법정동+지번 필터. `aptDong`·`rgstDate`는 등기 후에만 채워져 키 제외. 해제는 별도 행. 공급면적·호수·타입명 없음. 공개 시각은 비공개(신고 익일).
- **토허 데이터**: 서울부동산정보광장 내부 ajax가 유일한 실용 출처. 공개되는 건 **처리 완료 건(허가/취소/취하)**이지 신청이 아님. 면적·동·호·금액 없음. 10월 실거래 1건 대비 허가 12건 → 2~5주 선행 지표. 내부 ajax라 형식 변경 리스크.
- **Jenkins 함정**: 컨테이너가 호스트 docker 소켓을 쓰므로 `-v $PWD`가 호스트 경로로 해석돼 빈 디렉토리 → 테스트는 Dockerfile test 스테이지 안에서.
- GitHub deploy key는 레포당 1곳(422 `key is already in use`). Jenkins 자격증명은 UI 없이 `init.groovy.d`로 등록 가능.
- 2차 배포 전 자체 발견 버그: 첫 실행 적재분 전부에 `rgst_notified_at`을 채워 11건의 향후 등기 알림이 막힐 뻔 → 이미 등기된 행만 채우도록 수정.
- (신규) 공공데이터 API 30초 read timeout이 간헐 발생하나 1회성, 자가 복구.
- (신규) 서버 `.env` 앞 13줄 중복.
