## 3. 리뷰 중 심화 문답 (재사용 가치)

- **Slice 계약 누출 해법**: 서비스 계층에 순수 자바 `PageResult<T>(content, number, size, hasNext, totalElements)` + map() — Slice는 서비스 안에서 소비 종료. 입력 Pageable까지 바꿀지는 선택(실무 관례 허용).
- **@Query vs QueryDSL**: 문자열(런타임 오류·동적 쿼리 불가) vs 코드(컴파일 타임 타입 안전·BooleanBuilder 동적 조립·조건 재사용). 정적 단순 쿼리는 @Query 적정, 동적 검색부터 QueryDSL. 원조 정체 → OpenFeign fork 사용이 요즘 관례.
- **엔티티 검증 위치**: requireNonBlank를 엔티티에 두는 건 "불변식은 엔티티가 보장" 철학으로 정당(김승호 User 이메일 검증과 일관). 문제는 규칙 자체 — 첨부만 메시지가 허용되면 진짜 불변식은 "content 또는 첨부 중 하나"이고, 이 교차 검증은 둘 다 받는 생성자가 적임.
